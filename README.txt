易监控 PC 版 v1.23（加固版）

【重要】只能开一个
重复双击不会起第二个（第二个自动退出），避免同一笔收款被上报两次。

【启动】双击 EasyMonitorPC.exe（需管理员权限）

【本版加固内容】
  1. 密钥加密存储
     config.json 里的数据库密钥、商户密钥用 Windows DPAPI 加密
     （enc:v1: 前缀）。文件被拷走到别的机器/别的用户下解不开。

     注意：换电脑或重装系统后这些密钥解不开，需要重新「自动获取」
     和重新填商户密钥。这是加密的代价。

  2. 程序自校验
     exe 旁边有 integrity.dat 记录哈希。
     程序启动时比对，被改过会在「运行日志」里记 ERROR。

     局限：能改 exe 的人也能改 integrity.dat。
     这道防线只挡低成本篡改，不挡有决心的人。

  3. 二进制混淆（garble -literals）
     函数名、字符串字面量都被混淆。
     exe 里搜不到 /api/pay/、gh_id、config.json 这些明文。

【配置】
  1. 「微信账号」→「添加微信账号」
  2. 选中账号 →「自动获取」拿通行密钥
  3. 填通道 ID → 确定

【消息调试】
「微信账号」页右上角，打开即开始捕获，只显示新消息。
好友群聊显示昵称，群聊显示群名，收款消息带渠道标签。

【日志】
设置页「日志」：关闭 / 基本（推荐）/ 详细
日志在程序目录 run.log，超过 8MB 自动轮转。

【换设备（同微信版本）】
拷贝目录 → 自动重探微信路径和数据库目录 → 点「自动获取」重提密钥
（因 DPAPI 绑定用户，商户密钥需要重新填一次）

【支持】
  微信 4.x（4.1.13.63 实测）· 多账号 · 只读数据库

【版本】v1.23
