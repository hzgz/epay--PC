易监控 PC 版 v1.24

【重要】必须带 native 目录
程序需要同目录下的 native\WCDB.dll 和 native\wxtool_wcdb.dll。
不要只拷 exe。

【重要】只能开一个
重复双击不会起第二个，避免同一笔收款被上报两次。

【本版变化】
不再把 DLL 打进 exe。之前嵌入的那份从来没被用到
（代码优先读外部目录），却让 exe 从 18MB 涨到 33MB，
还把 WCDB 的 17673 个符号和 SQLCipher 参数原样暴露给逆向工具。
现在丢掉了。

【加固内容】
  1. 密钥加密（DPAPI）
     config.json 里的数据库密钥、商户密钥用 Windows DPAPI 加密。
     文件被拷走到别的机器/别的用户下解不开。
     代价：换电脑后要重新「自动获取」和重填商户密钥。

  2. 程序自校验
     integrity.dat 记录 exe 的 SHA256，启动时比对，
     被改过在「运行日志」里记 ERROR。
     局限：能改 exe 的人也能改 integrity.dat，只挡低成本篡改。

  3. 二进制混淆（garble -literals -tiny）
     函数名全变乱码，业务字符串不可搜。

【配置】
  1. 「微信账号」→「添加微信账号」
  2. 选中账号 →「自动获取」拿通行密钥
  3. 填通道 ID → 确定

【消息调试】
「微信账号」页右上角，打开即开始捕获，只显示新消息。

【日志】
设置页「日志」：关闭 / 基本（推荐）/ 详细
日志在程序目录 run.log，超过 8MB 自动轮转。

【换设备（同微信版本）】
拷贝整个目录（含 native）→ 自动重探微信路径和数据库目录
→ 点「自动获取」重提密钥（商户密钥因 DPAPI 需重新填一次）

【支持】
  微信 4.x（4.1.13.63 实测）· 多账号 · 只读数据库
