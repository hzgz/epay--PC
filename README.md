# 易监控PC版

微信收款消息监听工具（Windows）。只读转发微信收到的收款通知，不修改微信任何数据。

## 功能

- 监听微信 PC 端收款通知，转发到支付平台
- 支持两种接口：X-Ypay、码支付 V1
- 按关键词过滤（默认 15 个收款关键词）
- 收款记录查询、订单详情、回调状态
- 运行日志按级别/模块分类
- 系统托盘、关闭确认

## 环境要求

- Windows 10/11 x64
- 微信 PC 版 4.1.x（已测 4.1.13.63）
- WebView2 运行时（Win10/11 通常自带）

## 使用

1. 启动微信并登录
2. 运行 `EasyMonitorPC.exe`
3. 在「通知设置」中配置接口模式和平台参数
4. 收款时自动上报

## 构建

```bash
go build -ldflags="-H windowsgui -s -w" -o EasyMonitorPC.exe .
```

资源文件 `rsrc_windows_amd64.syso` 已包含图标和版本信息，不需要额外工具。
